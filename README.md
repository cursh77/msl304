# msl304

1. to run the program, first run the Python file (msl.py)
2. then use streamlit run app.py --server.runOnSave true 
3. to add more skills or change them or change the time slots, change them in the python file

4. Please make sure Streamlit is installed on your install. 
5. you may encounter a bug while trying to change data in the table for staff and the skillset, just re-enter the data, and it should be fixed.
